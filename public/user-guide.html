🚀 BrandFlow 사용자 가이드

환영합니다! BrandFlow는 마케팅 대행사와 클라이언트를 위한 통합 업무 관리 시스템입니다.

📋 시스템 개요

BrandFlow는 역할 기반 접근 제어(RBAC)를 통해 안전하고 효율적인 업무 환경을 제공합니다.

🎯 캠페인 관리

마케팅 캠페인 생성, 진행 상황 추적, 성과 분석

💰 재무 관리

매출 등록, 구매요청, 인센티브 관리

👥 팀 관리

사용자 권한 관리, 팀원 초대, 역할 할당

📊 대시보드

실시간 업무 현황, 성과 지표, 알림

👥 사용자 역할별 기능

🔑 슈퍼 어드민

  • 전체 시스템 관리: 모든 데이터 접근 및 관리
  • 대행사 어드민 생성: 새로운 대행사 관리자 계정 생성
  • 시스템 설정: 전역 설정 및 정책 관리
  • 통계 및 분석: 전체 시스템 성과 분석

🏢 대행사 어드민

  • 회사 내 데이터만 접근: 본인 소속 회사 데이터만 조회
  • 팀원 관리: 소속 직원 및 클라이언트 생성/관리
  • 구매요청 승인: 팀원의 구매요청 검토 및 승인
  • 캠페인 총괄 관리: 회사 캠페인 전체 관리

👤 직원

  • 본인 데이터만 접근: 자신이 담당하는 업무만 조회
  • 캠페인 실행: 할당된 캠페인 업무 수행
  • 구매요청 제출: 업무 수행에 필요한 자원 요청
  • 매출 등록: 완료된 업무의 매출 데이터 입력

🤝 클라이언트

  • 캠페인 현황 조회: 의뢰한 캠페인 진행 상황 확인
  • 결과물 확인: 완성된 컨텐츠 및 성과 리포트 조회
  • 커뮤니케이션: 담당자와 실시간 소통

🚀 시작하기

1단계: 로그인

  1. BrandFlow 시스템에 접속
  2. 관리자로부터 받은 이메일과 비밀번호 입력
  3. 로그인 버튼 클릭

2단계: 대시보드 확인

  1. 로그인 후 대시보드 화면 확인
  2. 현재 진행 중인 업무 현황 파악
  3. 알림 확인 (우상단 알림 아이콘)
  4. 본인의 역할에 맞는 메뉴 확인

3단계: 주요 기능 활용

  1. 캠페인 관리: 새 캠페인 생성 또는 기존 캠페인 관리
  2. 업무 등록: 캠페인 상세에서 세부 업무 등록
  3. 구매요청: 필요한 자원 구매요청 제출
  4. 매출 등록: 완료된 업무의 매출 데이터 입력

💡 주요 기능 사용법

🎯 캠페인 생성하기

  1. 캠페인 관리 메뉴 선택
  2. "새 캠페인 등록" 버튼 클릭
  3. 클라이언트 선택 (드롭다운에서 검색 후 선택)
  4. 캠페인 제목, 기간, 예산 등 입력
  5. "등록" 버튼으로 저장

📝 업무 등록하기

  1. 캠페인 목록에서 해당 캠페인 클릭
  2. 캠페인 상세 페이지에서 "주제 등록" 클릭
  3. 업무 제목, 업무 타입, 담당자 등 입력
  4. 시작일과 마감일 설정
  5. "등록" 버튼으로 저장

💸 구매요청 하기

  1. 구매요청 관리 메뉴 선택
  2. "구매요청 작성" 버튼 클릭
  3. 필요한 자원의 종류와 금액 입력
  4. 용도 및 상세 설명 작성
  5. 관련 캠페인 연결 (선택사항)
  6. "요청" 버튼으로 제출

💰 매출 등록하기

  1. 매출 관리 메뉴 선택
  2. "매출 등록" 버튼 클릭
  3. 담당자, 상품, 수량 선택
  4. 실제 판매 금액 입력
  5. 관련 캠페인 연결
  6. "등록" 버튼으로 저장

⚠️ 중요 사항

🔐 보안 주의사항

  • 비밀번호 관리: 정기적으로 비밀번호 변경
  • 로그아웃: 작업 완료 후 반드시 로그아웃
  • 권한 준수: 본인 권한 범위 내에서만 데이터 접근
  • 정보 보안: 고객 정보 외부 유출 금지

📊 데이터 입력 시 주의사항

  • 정확성: 모든 금액과 날짜는 정확히 입력
  • 완료 확인: 데이터 저장 후 반드시 확인
  • 승인 프로세스: 구매요청은 승인 후 실행
  • 백업: 중요 데이터는 정기적으로 백업됨

🆘 문제 해결

자주 발생하는 문제

❌ 로그인이 안 됩니다

  • 이메일과 비밀번호를 정확히 입력했는지 확인
  • 관리자에게 계정 활성화 상태 문의
  • 브라우저 캐시 삭제 후 재시도

📄 데이터가 로딩되지 않습니다

  • 인터넷 연결 상태 확인
  • 페이지 새로고침 (F5 또는 Ctrl+R)
  • 권한 범위 내 데이터인지 확인

💾 데이터 저장이 안 됩니다

  • 필수 입력 항목 모두 작성 확인
  • 금액 형식 확인 (숫자만 입력)
  • 파일 업로드 크기 제한 확인
